## Описание реализации и проверки

### `normalize.py` (Нормализация текста)

Программа удаляет пробельные символы по краям строки, заменяет последовательности пробелов внутри на один пробел. Регистр сохраняется. Выводит исходную и новую длину, нормализованный текст и количество слов.



**Проверки:**

| Ввод | Исходная длина | Новая длина | Нормализованный текст | Количество слов |
|------|----------------|-------------|------------------------|-----------------|
| `  Один   два  ` | 14 | 8 | Один два | 2 |
| *(пустая строка)* | 0 | 0 | *(пусто)* | 0 |
| `   ` (только пробелы) | 3 | 0 | *(пусто)* | 0 |

---

### `palindrome.py` (Палиндром)

Проверка текста на палиндром: игнорируется регистр и обычные пробелы `" "`, остальные символы (включая пунктуацию) сравниваются как есть. Если после очистки строка пуста — выводится «Нет текста», иначе «Палиндром» или «Не палиндром». Используется срез `[::-1]`.



**Проверки:**

| Ввод | Очищенная строка | Результат |
|------|------------------|-----------|
| `А роза упала на лапу Азора` | `арозаупаланалапуазора` | Палиндром |
| `а     ` | `а` | Палиндром |
| `строка из пробелов` | `строкаизпробелов` | Не палиндром |
| `Python` | `python` | Не палиндром |
| `А!` | `а!` | Не палиндром |

---

### `replace.py` (Замена с подсчётом)

Заменяются все двоеточия на дефисы. Сначала подсчитывается количество вхождений, затем выполняется замена. Выводится количество замен и новая строка.



**Проверки:**

| Ввод | Количество замен | Новая строка |
|------|------------------|--------------|
| `a::b:` | 3 | `a--b-` |
| `abc` | 0 | `abc` |
| `:::` | 3 | `---` |

---

### `variant.py` (Вариант 15: Начинается с гласной из «аеёиоуыэюя»)

Для каждого слова:
- Удалить с краёв символы `. , ! ? ; :` через `word.strip(".,!?;:")`.
- Перевести в нижний регистр.
- Пропустить пустые результаты.
- Проверить условие: начинается ли с одной из гласных «аеёиоуыэюя».

Вывести каждое подходящее слово на отдельной строке и общее количество. Повторы сохраняются. Если подходящих слов нет — «Нет совпадений» и количество 0.

**Контрольный текст:** `Анна, армия! Я читаю. Книга, край, рама.`  
После очистки и приведения к нижнему регистру: `анна`, `армия`, `я`, `читаю`, `книга`, `край`, `рама`.  
Подходящие (начинаются с гласной): `анна`, `армия`, `я`.  
Количество: 3.

**Проверки:**

| Ввод | Подходящие слова (по порядку) | Количество |
|------|-------------------------------|------------|
| `Анна, армия! Я читаю.` | анна<br>армия<br>я | 3 |
| `!!!` | *(нет слов после очистки)* | 0 (вывод: Нет совпадений) |
| *(пустая строка)* | *(нет слов)* | 0 (вывод: Нет совпадений) |

### `dopolnitelno.py` (Дополнительное задание: Палиндром без среза)

Реализована проверка палиндрома без использования среза `[::-1]`: сравниваются символы с начала и конца строки, двигаясь к центру.



**Сравнение результатов:**

| Ввод | Результат через `[::-1]` | Результат без среза | Совпадают? |
|------|---------------------------|---------------------|------------|
| `А роза упала на лапу Азора` | Палиндром | Палиндром | Да |
| `Python` | Не палиндром | Не палиндром | Да |
| `А!` | Не палиндром | Не палиндром | Да |

Это подтверждает, что оба подхода дают одинаковый результат при одинаковых правилах очистки.

## Пояснения по ключевым темам (для защиты работы)

- **Неизменяемость строк:** строка в Python не может быть изменена «на месте». Методы вроде `lower()`, `strip()`, `replace()` возвращают новую строку. Если не присвоить результат переменной, исходная строка не изменится. Пример: `text.lower()` сам по себе ничего не делает с `text`; нужно `text = text.lower()` или использовать результат сразу.
- **Слово vs подстрока:** в этой работе «слово» — это элемент списка, полученный через `split()`, то есть последовательность непробельных символов. Подстрока — любая часть строки, которая может быть внутри слова или пересекать границы слов. Правила нормализации и обработки пунктуации нужно задать до написания кода, иначе разные трактовки приведут к разным результатам (например, считать ли «Анна,» одним словом или «Анна»).
- **Почему правила пунктуации задаются заранее:** в задании 2 пунктуация участвует в сравнении, а в задании варианта — удаляется с краёв. Если не зафиксировать эти правила, программа будет вести себя непоследовательно.
- **Использование `strip` с набором символов:** `word.strip(".,!?;:")` удаляет указанные символы только с краёв, не затрагивая внутренние. Это важно, чтобы не потерять смысловые части слов.
