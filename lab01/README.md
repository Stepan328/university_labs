### `workload.py` (Учебная нагрузка)

Запрашивает:
- Два предмета, количество занятий в неделю, продолжительность одного занятия (в минутах).
- Доступное время в неделю (в часах).

Вычисляет:
- Нагрузку по каждому предмету в минутах.
- Общую нагрузку в минутах и часах (с двумя знаками).
- Остаток свободного времени в часах.
- Нагрузку за 4 одинаковые недели (в часах, два знака).

**Пример входных данных:**
- Предмет 1: Математика, 3 занятия, 90 минут
- Предмет 2: Физика, 2 занятия, 45 минут
- Доступно: 10 часов

**Ожидаемый результат:**
```text
Математика: 270 мин
Физика: 90 мин
Общая нагрузка: 360 мин = 6.00 ч
Остаток свободного времени: 4.00 ч
Нагрузка за 4 недели: 24.00 ч
```

**Проверки:**
- Обычный случай (пример выше).
- Нулевое количество занятий по обоим предметам: нагрузка 0, остаток равен доступному времени.
- Проверка формата: часы выводятся с двумя знаками после запятой.

### `debug.py` (Поиск и исправление ошибок)

Три фрагмента с ошибками и их исправления:

**Фрагмент А:** требовалось сложить числа 5, а не объединить строки.  
Исходный код был некорректен синтаксически и логически.  
Исправленный вариант:
```python
first = 3
second = 2
print(first + second)
print("Типы до преобразования:", type(first), type(second))
```
**Объяснение:** переменные должны быть числами (`int`), тогда `+` выполняет сложение. Типы: `int` и `int`.

**Фрагмент Б:** требуется указать возраст через год.  
Ошибка: `input` переопределялся, а функция вызывалась неправильно.  
Исправленный вариант:
```python
age = int(input("Возраст: "))
print(age + 1)
print("Тип age:", type(age))
```
**Объяснение:** `input()` возвращает строку, её нужно преобразовать в `int`. Нельзя называть переменную `input`, иначе теряется доступ к встроенной функции. Тип: `int`.

**Фрагмент В:** среднее арифметическое трёх чисел 4, 7, 10 → результат 7.0.  
Ошибка: неверный порядок присваивания и синтаксис.  
Исправленный вариант:
```python
first = 4
second = 7
third = 10
average = (first + second + third) / 3
print(average)
print("Тип average:", type(average))
```
**Объяснение:** сначала присваиваем значения, затем считаем среднее. Деление `/` в Python всегда возвращает `float`. Тип: `float`.

**Проверки:** для каждого фрагмента проверяем ожидаемые результаты: 5, 18, 7.0, а также типы значений.

### `swap.py` (Обмен значениями)

Вводятся названия двух аудиторий в переменные `first_room` и `second_room`. Значения выводятся, затем меняются местами с помощью третьей переменной, и результат выводится снова.

**Пример:**
- Ввод: А-101, Б-202
- Вывод до обмена: А-101, Б-202
- После обмена: Б-202, А-101

**Объяснение назначения временной переменной:** она хранит одно из значений, пока происходит «перекладывание» другого значения. Это классический способ обмена без потери данных.

**Проверки:**
- Разные названия: корректный обмен.
- Одинаковые названия: остаются без изменений.

### `variant.py` (Индивидуальный вариант №15: Туристический магазин)

Реализован расчёт заказа из двух позиций с учётом скидки (в процентах от стоимости товаров, без учёта доставки).

**Позиции для варианта 15:** фонарики и компасы.

Ввод:
- Название заказа: «Туристический магазин».
- Имя заказчика.
- Для каждой позиции: название, количество (целое), цена за единицу (дробная).
- Стоимость доставки (неотрицательная).
- Внесённая сумма (не меньше итоговой суммы к оплате).
- Скидка в процентах (от 0 до 100).

Вычисления:
- Стоимость каждой позиции = количество × цена.
- Стоимость товаров без доставки.
- Размер скидки в рублях = стоимость товаров × (скидка / 100).
- Итоговая сумма к оплате = стоимость товаров − скидка + доставка.
- Сдача = внесённая сумма − итоговая сумма.

Все денежные значения выводятся с двумя знаками после запятой.

**Собственный пример заказа (ручной расчёт до запуска):**

- Заказ: «Туристический магазин»
- Заказчик: Иван Иванов
- Позиция 1: Фонарики, 3 шт., 850.00 руб.
- Позиция 2: Компасы, 2 шт., 650.00 руб.
- Доставка: 300.00 руб.
- Внесено: 5000.00 руб.
- Скидка: 15%

Расчёты:
- Стоимость позиции 1: 3 × 850.00 = 2550.00
- Стоимость позиции 2: 2 × 650.00 = 1300.00
- Товары без доставки: 2550.00 + 1300.00 = 3850.00
- Скидка: 3850.00 × 0.15 = 577.50
- Итоговая сумма: 3850.00 − 577.50 + 300.00 = 3572.50
- Сдача: 5000.00 − 3572.50 = 1427.50

**Ожидаемый вывод:**
```text
Заказ: Туристический магазин
Заказчик: Иван Иванов
Фонарики | 3 | 850.00 | 2550.00
Компасы | 2 | 650.00 | 1300.00
Стоимость товаров: 3850.00 руб.
Скидка: 577.50 руб.
Итого к оплате: 3572.50 руб.
Внесено: 5000.00 руб.
Сдача: 1427.50 руб.
```

**Проверки:**
- Нулевое количество одной позиции: стоимость этой позиции 0.
- Нулевая доставка: итоговая сумма = товары − скидка.
- Точная оплата без сдачи: внесённая сумма равна итоговой.
- Названия из нескольких слов: корректно считываются через `input()`.

## Пояснения по ключевым темам (для защиты работы)

- **Разница между строкой и числом:** `input()` всегда возвращает строку (`str`). Для вычислений её нужно преобразовывать: `int()` для целых, `float()` для дробных. Если этого не сделать, операции вроде сложения будут либо невозможны, либо дадут конкатенацию строк.
- **Порядок вычислений:** умножение и деление выполняются раньше сложения и вычитания. Скобки позволяют изменить приоритет.
- **Назначение временной переменной при обмене:** она временно хранит одно значение, чтобы не потерять его при перезаписи. Это гарантирует корректность обмена без потери данных.
- **Форматирование денежных значений:** используется f-строка с форматом `:.2f`, например: `f"{value:.2f}"`. Это выводит ровно два знака после запятой, даже если число целое.
