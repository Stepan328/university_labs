## 📂 Структура лабораторной работы
В данной лабораторной работе (`lab01`) представлены следующие файлы с исходным кодом:
1. `hello.py` — вывод строк.
2. `profile.py` — карточка студента с расчетом возраста через 4 года и времени подготовки.
3. `workload.py` — расчет учебной нагрузки по двум предметам и остатка свободного времени.
4. `debug.py` — исправление ошибок (типы данных, деление, операции со строками).
5. `swap.py` — обмен значениями двух переменных (названий аудиторий) с использованием временной переменной.
6. `variant.py` — расчет стоимости заказа (индивидуальный вариант № 15) с учетом скидки и сдачи.

## 🚀 Инструкция по запуску программ

Для запуска программ на вашем компьютере должен быть установлен **Python 3** (рекомендуется версия 3.13 или новее).

1. Откройте терминал (командную строку) в папке с нужной лабораторной (`.../lab01`).
2. Запустите любой файл с помощью команды:
   ```bash
   python имя_файла.py
   ```

## 💡 Дополнительные объяснения

* **Различие строки и числа:** строка имеет тип данных `str` и хранит произвольный набор символов. При сложении строк происходит конкатенация (склеивание), а при умножении на число — повторение строки. Число (`int` или `float`) участвует в классических математических операциях.
* **Порядок вычислений:** приоритет операций аналогичен математическому (сначала умножение/деление, затем сложение/вычитание). Круглые скобки позволяют явно изменить порядок выполнения действий.
* **Назначение временной переменной:** необходима для безопасного обмена значениями между двумя переменными без их перезаписи и потери данных в процессе последовательного присваивания.
