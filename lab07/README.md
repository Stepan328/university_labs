## Описание реализации и проверок

### `functions.py`: функции без ввода/вывода

Все функции в этом файле не вызывают `input()` или `print()`. Они принимают параметры и возвращают результат.

#### `sum_digits(number)`
Принимает целое число (может быть отрицательным), возвращает сумму цифр его модуля. Для `0` результат `0`. Используется целочисленная арифметика (`//`, `%`).



**Проверки:**

| Ввод | Ожидаемый результат |
|------|---------------------|
| `0` | `0` |
| `507` | `12` (5+0+7) |
| `-507` | `12` |

#### `average(numbers)`
Принимает список чисел, возвращает среднее арифметическое. Если список пуст — возвращает `None`. Исходный список не изменяется.



**Проверки:**

| Ввод | Ожидаемый результат |
|------|---------------------|
| `[]` | `None` |
| `[2, 4, 6]` | `4.0` |
| `[1, 2, 3, 4]` | `2.5` |

#### `normalize_text(text)`
Нормализует текст: нижний регистр, удаление пробелов по краям, замена множественных пробелов на один. Правила аналогичны работе №5.


**Проверки:**

| Ввод | Ожидаемый результат |
|------|---------------------|
| `"  ПРИВЕТ   Мир  "` | `"привет мир"` |
| `"   "` | `""` (пустая строка) |
| `"Один   два"` | `"один два"` |

#### `select_numbers(numbers, threshold)` — вариант 15
Возвращает новый список, содержащий числа, для которых модуль строго между `threshold` и `2 * threshold`. Порядок и повторы сохраняются.




**Контрольный пример:** `[-5, 0, 2, 5]`, порог `2`.  
Границы: `2 < abs(x) < 4`.  
Подходящие: нет (у `-5` модуль 5 — не подходит, у `5` модуль 5 — не подходит).  
Результат: `[]`.

**Дополнительные проверки:**

| Ввод (список, порог) | Ожидаемый результат | Пояснение |
|----------------------|---------------------|-----------|
| `[-5, 0, 2, 5], 2` | `[]` | Ни одно число не попадает в интервал (2, 4) |
| `[3, -3, 1, 7], 2` | `[3, -3]` | Модули 3 и 3 попадают в (2, 4); 1 и 7 — нет |
| `[], 5` | `[]` | Пустой список → пустой результат |
| `[4, -4, 8], 3` | `[4, -4]` | Интервал (3, 6); 4 и -4 подходят, 8 — нет |

Важно: исходный список после вызова функции остаётся неизменным (проверяется в тестах сравнением с копией).

#### `is_palindrome(text)` — дополнительное задание
Проверяет строку на палиндром по правилам работы №5: игнорируются регистр и пробелы, остальные символы сравниваются как есть. Для пустого нормализованного текста возвращается `False`.



**Проверки:**

| Ввод | Ожидаемый результат |
|------|---------------------|
| `"А роза упала на лапу Азора"` | `True` |
| `"Python"` | `False` |
| `""` | `False` |
| `"а     "` | `True` (после нормализации: `"а"`) |

## Пояснения по ключевым темам (для защиты работы)

- **Возврат vs вывод:** `return` передаёт значение обратно в место вызова (для дальнейшей обработки), `print` просто показывает текст на экране. Функции должны возвращать результаты, а `print` используется только в `main` или тестах.
- **Локальные переменные vs параметры:** переменные внутри функции (например, `total` в `sum_digits`) видны только внутри неё. Параметры (`number`, `numbers`, `threshold`) — это входные данные, которые передаются при вызове.
- **Почему не нужен `global`:** все нужные данные передаются через параметры, а результат возвращается через `return`. Это делает функции независимыми и удобными для тестирования.
- **Зачем нужны отдельные тесты:** автоматические проверки (`assert`) позволяют быстро убедиться, что функции работают корректно на разных данных, в том числе на граничных случаях.
- **Строгая проверка границ:** для варианта 15 важно использовать строгое неравенство (`<`), чтобы корректно обрабатывать числа на границах интервала.
