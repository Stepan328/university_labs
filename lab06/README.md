## Описание реализации и проверки

### `statistics.py` (Статистика)

Программа принимает целые числа одной строкой через пробел. Выводит количество, сумму, минимум, максимум и среднее (с двумя знаками после запятой). Если ввод пустой — выводится «Нет данных». При этом не вызываются `min()/max()` и не происходит деления на ноль.



**Проверки:**

| Ввод | Ожидаемый результат |
|------|---------------------|
| `-2 0 5 3` | Количество: 4, Сумма: 6, Минимум: -2, Максимум: 5, Среднее: 1.50 |
| `8` | Количество: 1, Сумма: 8, Минимум: 8, Максимум: 8, Среднее: 8.00 |
| *(пустая строка)* | Нет данных |

### `transform.py` (Независимое преобразование)

Создаётся новый список, где отрицательные числа заменены на их модули. Исходный список должен остаться без изменений.



**Проверки:**

| Ввод | Исходный список | Новый список |
|------|-----------------|--------------|
| `-2 0 5 -2` | [-2, 0, 5, -2] | [2, 0, 5, 2] |
| *(пустая строка)* | [] | [] |

Это показывает, что исходный список сохранён.

| `7 7` | 7 | [0, 1] |
| `-3 -1 -2` | -1 | [1] |

### `variant.py` (Вариант 15: Числа, оканчивающиеся на 2 в записи модуля)

Условие: `abs(x) % 10 == 2`.  
Программа вводит список целых чисел одной строкой, фильтрует по условию, выводит:
- отфильтрованный список (в исходном порядке),
- количество элементов,
- сумму,
- отсортированную по возрастанию копию (без изменения исходного отфильтрованного списка).

**Контрольный ввод:** `-8 -3 0 6 6 1`  
Подходящие: нет (ни одно число не оканчивается на 2 по модулю).  
Результат: список `[]`, количество `0`, сумма `0`, отсортированная копия `[]`.

**Дополнительный набор (непустой результат):** `2 -12 5 22`  
Подходящие: `[2, -12, 22]`.  
Количество: 3, сумма: 12, отсортированная копия: `[-12, 2, 22]`.

**Проверки:**

| Ввод | Отфильтрованный список | Количество | Сумма | Отсортированная копия |
|------|------------------------|------------|-------|------------------------|
| `-8 -3 0 6 6 1` | [] | 0 | 0 | [] |
| `2 -12 5 22` | [2, -12, 22] | 3 | 12 | [-12, 2, 22] |
| *(пустая строка)* | [] | 0 | 0 | [] |

**Пояснение условия:** `abs(x)` убирает знак, `% 10` даёт последнюю цифру. Так проверяется окончание на 2 независимо от знака.

## Пояснения по ключевым темам (для защиты работы)

- **Отличие `append()` от присваивания по индексу:**  
  `items.append(value)` добавляет элемент в конец списка (длина увеличивается).  
  `items[i] = value` заменяет уже существующий элемент по индексу `i` (длина не меняется). Нельзя присвоить по индексу, которого ещё нет — будет ошибка `IndexError`.

- **Отличие `sorted(items)` от `items.sort()`:**  
  `sorted(items)` возвращает новый отсортированный список, исходный остаётся без изменений.  
  `items.sort()` сортирует список «на месте» и возвращает `None`; исходный список изменяется.

- **Сохранение исходного списка:**  
  В задании 2 важно не менять `numbers`, а создать отдельный список для преобразованных значений. Для этого используют либо цикл с `append`, либо списковое включение. Простое присваивание `copy = numbers` не создаёт новый список — это вторая ссылка на тот же объект. Для независимого списка используют `numbers.copy()` или конструктор `list(numbers)`.

- **Обработка пустого ввода:**  
  Пустая строка после `.split()` даёт пустой список. В таких случаях не вызывают `min()`, `max()` и не делят на ноль. Вместо этого выводят специальное сообщение и завершают обработку.
